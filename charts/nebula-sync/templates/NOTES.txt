{{- if not .Values.sync.cron }}

WARNING: sync.cron is not set. nebula-sync performs a single synchronization
and then exits; the Deployment will keep restarting the pod. For continuous
operation set sync.cron (e.g. "0 * * * *"). For a one-shot sync a CronJob is
a better fit than this chart's Deployment.

{{- end }}

when they next run gravity themselves. Set it to true to re-run gravity on
the replicas after each sync.

{{- end }}
